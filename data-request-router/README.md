# Data request router

**The problem:** "Can I get a number for X?" bounces between people for days because the question is vague, the answer already exists, or it went to the wrong owner.

**What it does:** Turns the ask into one exact question with the decision it supports, the metric and its definition, filters, comparison, and deadline. Checks for an existing dashboard or analysis first, then routes to the right owner.

**Use it with:** any data request, or a queue of them.

**You get:** a clear, routed request, or a link to the answer that already exists.
