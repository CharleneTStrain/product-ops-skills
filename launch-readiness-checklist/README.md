# Launch readiness checklist

**The problem:** "Is it ready?" usually means "is the code done?" Support, sales, docs, and billing find out about the launch from customers.

**What it does:** Sizes the launch into a tier, walks a cross-functional checklist that scales to that tier, requires evidence before marking anything ready, and puts one named owner on every gap.

**Use it with:** a launch plan, project tracker, or a description of where each team stands.

**You get:** a go / no-go readout with blockers, risks, and owners.
