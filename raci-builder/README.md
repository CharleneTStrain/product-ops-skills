# RACI builder

**The problem:** On cross-team projects, two people think they make the final call, or nobody does, and the work stalls in between.

**What it does:** Builds a RACI chart with tasks and decisions as rows and named people as columns, then checks it for the usual failures: no one accountable, two people accountable, too many consulted, and single-person bottlenecks.

**Use it with:** a project plan, launch checklist, or a description of who's involved.

**You get:** a RACI chart, flagged problems with suggested fixes, and the ownership questions that still need an answer.
