# Tool stack audit

**The problem:** Teams add tools and rarely remove them. Nobody knows the total cost, which tools overlap, or who owns the renewal.

**What it does:** Inventories every tool by the job it does, who uses it, seats paid vs. active, cost, renewal date, and owner. Flags overlap, low use, missing owners, and upcoming renewals, then recommends keep, right-size, consolidate, cut, or investigate, including what a consolidation would lose.

**Use it with:** a spend report, software list, or a description of what each team uses.

**You get:** an audit with renewal decisions at the top. It never cancels or changes anything.
