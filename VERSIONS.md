# Versions

## 1.0.0 — October 27, 2026

First packaged release.

- 31 product ops skills across six categories, moved into `skills/`
- New foundation skill, **product-ops-context**, that writes `.agents/product-ops-context.md`; every other skill reads it first
- Every skill now ends with **Related skills**, naming what it hands off to
- Installs as a Claude Code plugin, through `npx skills`, or by copying folders
- MIT license, contributing guide, skill request form, and `validate-skills.sh`
