# Request intake triage

**The problem:** Requests arrive from sales, support, customers, and leadership in every format. Some get lost, some jump the line because of who asked, and the same ask gets filed five times.

**What it does:** Restates each request as the underlying need, tags type, theme, and urgency based only on evidence, spots duplicates, and gives every request one next step and one owner. It never promises delivery.

**Use it with:** a batch of requests from Slack, email, tickets, call notes, or a form export.

**You get:** a sorted intake list (act now, route, backlog by theme, decline) plus the exact questions to send back to requesters.
