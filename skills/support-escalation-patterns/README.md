# Support escalation patterns

**The problem:** Support answers the same issue a hundred times, and the product team never sees the pattern behind it.

**What it does:** Groups tickets by root cause (not just the category agents picked), sizes each pattern by volume, escalations, time to resolve, and accounts affected, and labels what would fix it: a bug, a product gap, usability, docs, or onboarding. Calls out quick wins that need no engineering.

**Use it with:** a ticket export or escalation log.

**You get:** ranked patterns with suggested owners and the limits of the data.
