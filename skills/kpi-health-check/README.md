# KPI health check

**The problem:** Weekly metrics reviews either over-react to normal noise or miss the one number that's actually drifting.

**What it does:** Lines up each KPI against last period, target, and its normal range; computes the changes; marks each on track, watch, off track, or can't tell; and suggests what to check next as questions, never as assumed causes.

**Use it with:** a dashboard export or a table of recent numbers.

**You get:** a one-screen readout. If everything's fine, it says so in two lines.
