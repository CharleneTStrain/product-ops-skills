# Feedback tagging

**The problem:** Customer feedback piles up across calls, tickets, and surveys as unstructured text. Nobody can say how often something comes up, so the loudest anecdote wins.

**What it does:** Sets a small, defined tag list (or uses yours), tags every item for type, product area, theme, sentiment, and segment using the customer's own words, and counts the results. Anything that doesn't fit is surfaced as a possible new theme.

**Use it with:** survey exports, call notes, support tickets, app reviews, or interview transcripts.

**You get:** a tagged table, theme counts with sentiment and segment mix, and the tag definitions used.
