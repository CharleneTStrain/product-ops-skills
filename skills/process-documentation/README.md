# Process documentation

**The problem:** Critical workflows live in one person's head. When they're out, the work stops or gets done wrong.

**What it does:** Pulls the trigger, outcome, roles, tools, steps, decision points, and failure points out of rough notes, then writes an SOP a new hire could follow on the first try. Missing pieces become open questions, not guesses.

**Use it with:** rough notes, a walkthrough transcript, a voice memo, or a Slack explanation.

**You get:** a step-by-step SOP with a troubleshooting table and open questions.
