# Information debt audit

**The problem:** Every change that isn't reflected in the docs leaves debt behind: stale pages, duplicates, conflicting answers, and pages nobody owns. People stop trusting the wiki and start asking in Slack.

**What it does:** Inventories a workspace, diagnoses each item using Abby Covert's three types of information problems (too much, not enough, not the right information), scores findings by risk and reach, and recommends one action per item with an owner.

**Use it with:** a folder listing, wiki export, page list, or a set of docs.

**You get:** a prioritized cleanup readout. It recommends; owners decide what gets archived or deleted.
