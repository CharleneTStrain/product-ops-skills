# Product metrics definitions

**The problem:** Two dashboards show different "active users" numbers, and every meeting starts by arguing which one is right.

**What it does:** Collects every version of a metric in use, shows where they conflict, and writes one definition per metric: plain-language meaning, exact formula, what counts and what doesn't, time window, source, and owner. Conflicts go to a named person to decide.

**Use it with:** dashboards, metric lists, spreadsheets, or a description of how numbers are calculated today.

**You get:** a metrics glossary plus a list of conflicts to resolve.
