# Duplicate request merging

**The problem:** The same need gets filed five different ways, so a top customer ask looks like five small ones.

**What it does:** Groups requests by the underlying need, not the proposed solution, merges true duplicates while keeping every requester and piece of evidence, counts unique requesters, and flags close-but-different pairs for a person to decide.

**Use it with:** a backlog, ideas board, Productboard or Canny export, or request spreadsheet.

**You get:** merged requests ranked by real demand, plus a list of possible duplicates to review.
