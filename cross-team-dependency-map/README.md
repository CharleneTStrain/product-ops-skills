# Cross-team dependency map

**The problem:** Launches slip because one team was waiting on another that didn't know it was being waited on.

**What it does:** Lists every specific thing one team needs from another, with a person on each side, a needed-by date, and whether the provider actually agreed. Flags unagreed asks, chains, hubs, circular waits, and missing dates, and puts a next step on each risk.

**Use it with:** a project plan, launch checklist, tickets, or a description of who's working on what.

**You get:** a dependency table with risks up top, plus an optional swim lane or flow diagram.
