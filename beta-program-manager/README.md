# Beta program manager

**The problem:** Betas run with no clear question, drift on for months, and end when someone gets tired of them instead of when they've answered anything.

**What it does:** Writes a beta plan with two to four learning questions and checkable exit criteria set up front, tracks who's invited and actually active, ties feedback back to the learning questions, and produces a go live / extend / stop readout.

**Use it with:** a feature description, a list of candidate customers, or beta feedback to date.

**You get:** a beta plan, a participant tracker, and an exit readout.
