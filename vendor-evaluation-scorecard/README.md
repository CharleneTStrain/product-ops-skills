# Vendor evaluation scorecard

**The problem:** Tool decisions get made on the best demo or the loudest opinion, and nobody can explain the choice six months later.

**What it does:** Sets must-haves and weighted criteria before looking at vendors, gathers evidence per criterion with its source, scores each on a defined 1–5 scale (no evidence scores 1), computes weighted totals, and recommends a winner and a runner-up with the risks.

**Use it with:** demo notes, trial results, pricing, docs, or reference call notes.

**You get:** a scorecard and a recommendation the team can defend.
