Sheet 02 · How it worksClick any skill to open it

One context file. Six kinds of work.

Run product-ops-context once. It writes down your product, teams, who decides what, your meetings, your tools, and your metric definitions. Every other skill reads that file first, so it only asks you for what's specific to the job.

Sheet 03 · RulesBuilt into all 31

What every skill refuses to do

The same four rules run through the whole library, so outputs hold up when someone checks them later.

Rule 1

Every open item gets one named owner.

"Marketing" isn't an owner. Neither is "the team."

Rule 2

Discussed and decided stay separate.

A lean in a meeting never shows up as a decision.

Rule 3

Nothing gets invented.

If the notes don't say why, the output says "Not recorded."

Rule 4

Skills recommend. People decide.

The agent does the sorting and drafting. A person makes the call.
